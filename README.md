# Riyadvi Full Stack Website

## Overview

Riyadvi Full Stack Website is a responsive company website developed using React.js (Vite) for the frontend and Django REST Framework for the backend.

The application includes:

- Home
- About
- Services
- Portfolio
- Blog
- Careers
- Contact Form

---

## Tech Stack

### Frontend
- React.js
- Vite
- React Router
- Axios
- HTML5
- CSS3

### Backend
- Python
- Django
- Django REST Framework

### Database
- SQLite

### Deployment
- Frontend – Vercel
- Backend – Render

---

## Features

- Responsive UI
- REST API Integration
- Blog Management
- Careers Listing
- Contact Form
- CORS Configuration
- Full Stack Deployment

## Backend Setup

```bash
cd backend

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```
